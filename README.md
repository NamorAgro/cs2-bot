# Steam-бот: CS2, Rust и Dota 2

Рабочая основа — `bot.js` из коммита `7a5d4c9`, включая прежние исправления загрузки через curl, кэша инвентаря, восстановления Steam-сессии и обработки трейдов.

Изменения относительно этой версии:
- В `GAMES` добавлена `dota2`: appId `570`, contextId `2`.
- Сообщение трейда использует название выбранной игры.

Весь исполняемый код снова находится в `bot.js`. Дополнительные локальные модули и новое требование Node.js 22 убраны. Настройки и зависимости восстановлены по рабочей версии; существующий серверный `.env`, maFile и `offer-callbacks.json` используются как раньше.

## Подключение Dota-магазина

Сайт передаёт `game: "dota2"` в `/get-inventory` и `/create-offer`. Запрос без игры по-прежнему означает CS2. Rust использует `game: "rust"`.

Все сайты используют существующий серверный `BOT_API_KEY` общего бота. Для Dota необходимо задать этот же ключ в окружении магазина. Серверный ключ менять не нужно. Добавленная ранее настройка `BOT_CLIENTS_JSON` больше не используется. Адрес callback передаёт сайт; для Dota он формируется из `BASE_URL=https://www.dotaskin.io`.

## Обновление работающего сервера

Заменить только `bot.js` в `/root/var/www/cs2-bot/` актуальным локальным файлом. Затем:

```bash
cd /root/var/www/cs2-bot
node --check bot.js
pm2 restart steam-bot
pm2 status
pm2 logs steam-bot --lines 40 --nostream
```

При обновлении через Git сначала закоммитить и отправить локальную правку, затем получить её на сервере обычным способом. Локальные изменения автоматически на DigitalOcean не попадают.

Для этой правки установка новых зависимостей и архив с `lib/*.js` не требуются. Серверные секреты и данные сделок сохраняются. Реальная проверка выкупа проводится отдельно после восстановления запуска бота.
